# Footnotes Made Easy

**Version:** 3.2.0  
**Requires WordPress:** 6.0 or higher  
**Requires PHP:** 7.4 or higher  
**License:** GPL-2.0+  
**Download:** [WordPress.org](https://wordpress.org/plugins/footnotes-made-easy/)

Footnotes Made Easy is a free WordPress plugin that lets you add professional footnotes to any post or page using a simple inline syntax. Footnotes are automatically numbered, linked, and displayed at the bottom of your content.

## How it works

Wrap any footnote content in double parentheses anywhere in your post:

```
This is your post content.((This is the footnote text.))
```

When the post is published, the plugin automatically:

- Replaces the marker with a numbered superscript
- Generates a numbered footnotes list at the bottom of the post
- Creates clickable links between each inline marker and its reference

## Free plugin features

- Simple `(( ))` inline syntax — no shortcodes, no blocks required
- Automatic sequential numbering
- Clickable back-and-forth navigation between markers and references
- Configurable identifier style — numbers, letters, or symbols
- Optional tooltips — show footnote content on hover
- Suppress controls — hide footnotes on homepages, archives, feeds, and custom URLs
- Custom delimiters — change `(( ))` to any opening and closing tags you prefer
- Export and import settings across multiple sites
- Multisite support — network-managed or per-subsite override mode
- Compatible with the Classic Editor and Gutenberg block editor

## Pro features `PRO`

Footnotes Made Easy Pro is a premium add-on that extends the free plugin with:

- **Citations** — APA, MLA, and Chicago style formatting across 10 source types
- **DOI & ISBN auto-fetch** — paste a DOI or ISBN and source metadata fills in automatically
- **Footnote Library** — save footnotes once and reuse them across all posts
- **Gutenberg sidebar panel** — manage footnotes without leaving the block editor
- **Priority support** — direct support from the AltviseWP team
