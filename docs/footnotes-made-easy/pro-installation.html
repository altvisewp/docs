Installation Pro

Footnotes Made Easy Pro Edit this page

Footnotes Made Easy Pro is a premium plugin delivered as a ZIP file. It is not available on WordPress.org.

Before you begin

Footnotes Made Easy Pro requires the free Footnotes Made Easy plugin to be installed and active before installing the Pro add-on. If the free plugin is not active, the Pro plugin will deactivate itself automatically with a notice.

Install the free plugin first →

Step 1 — Download the Pro plugin

  1. Log in to your account at altvisewp.com
  2. Go to My Account → My Downloads
  3. Click Download next to Footnotes Made Easy Pro
  4. Save the ZIP file to your computer

Step 2 — Install via WordPress dashboard

  1. Log in to your WordPress admin dashboard
  2. Go to Plugins → Add New
  3. Click Upload Plugin at the top of the page
  4. Click Choose File and select the footnotes-made-easy-pro.zip file
  5. Click Install Now
  6. Click Activate Plugin

Step 3 — Activate your license

After activation, you will be redirected to the License page. Enter your license key to unlock all Pro features.

License activation guide →

Manual installation via FTP

  1. Extract the footnotes-made-easy-pro.zip file on your computer
  2. Connect to your server via FTP or your hosting file manager
  3. Upload the extracted footnotes-made-easy-pro folder to /wp-content/plugins/
  4. Log in to your WordPress admin dashboard
  5. Go to Plugins → Installed Plugins
  6. Find Footnotes Made Easy Pro and click Activate
  7. Go to Footnotes → License and enter your license key

Updating the Pro plugin

When a new version of Footnotes Made Easy Pro is available, an update notification will appear in your WordPress dashboard under Dashboard → Updates and on the Plugins page — provided your license is active.

Click Update now to install the update automatically. No manual download required.

If your license has expired, updates will no longer be delivered automatically. Renew your license at altvisewp.com to restore update access.

Uninstalling

  1. Go to Plugins → Installed Plugins
  2. Click Deactivate under Footnotes Made Easy Pro
  3. Click Delete

Deactivating your license before uninstalling is recommended so the activation count is freed up for use on another site. Go to Footnotes → License → Deactivate license before deleting the plugin.
