# Installation

Footnotes Made Easy can be installed directly from the WordPress dashboard or manually via FTP.

## Method 1 — Install from WordPress dashboard 

<img width="1640" height="624" alt="rererere" src="https://github.com/user-attachments/assets/e1200b8e-aeaf-4277-9c60-a2e4e03cd07e" />

1. Log in to your WordPress admin dashboard
2. Go to **Plugins → Add New**
3. Search for **Footnotes Made Easy**
4. Click **Install Now** on the plugin
5. Click **Activate** once installation is complete

The plugin is now active. A new **Footnotes** menu item will appear in your admin sidebar.

## Method 2 — Manual installation via FTP

1. Download the plugin ZIP file from [WordPress.org](https://wordpress.org/plugins/footnotes-made-easy/)
2. Extract the ZIP file on your computer
3. Connect to your server via FTP or your hosting file manager
4. Upload the extracted `footnotes-made-easy` folder to `/wp-content/plugins/`
5. Log in to your WordPress admin dashboard
6. Go to **Plugins → Installed Plugins**
7. Find **Footnotes Made Easy** and click **Activate**

## Method 3 — Upload via WordPress dashboard

1. Download the plugin ZIP file from [WordPress.org](https://wordpress.org/plugins/footnotes-made-easy/)
2. Log in to your WordPress admin dashboard
3. Go to **Plugins → Add New**
4. Click **Upload Plugin** at the top of the page
5. Click **Choose File**, select the ZIP file, and click **Install Now**
6. Click **Activate Plugin**

## After activation

After activating the plugin, navigate **Footnotes Made Easy Dashboard**.

No configuration is required to start using the plugin — it works immediately with the default `(( ))` syntax.

## Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher
- A WordPress site where you can install plugins (self-hosted WordPress.org installations only — not WordPress.com free or starter plans)

## Uninstalling

To uninstall the plugin:

1. Go to **Plugins → Installed Plugins**
2. Click **Deactivate** under Footnotes Made Easy
3. Click **Delete**

By default, the plugin's settings are removed when it is deleted. If you want to preserve your settings for a future reinstall, go to **Footnotes → Tools → Data on uninstall** and enable **Preserve settings** before deleting.
