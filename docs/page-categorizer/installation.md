# Installation

Page Categorizer has no dependencies — it works with a standard WordPress installation.

## Requirements

- WordPress 6.0 or higher
- PHP 7.4 or higher

## Method 1 — Install from WordPress dashboard (recommended)

1. Log in to your WordPress admin dashboard
2. Go to **Plugins → Add New**
3. Search for **Page Categorizer**
4. Click **Install Now** on the plugin by Patrick Lumumba
5. Click **Activate**

That's it. Visit any Page editing screen and you will see the Categories and Tags meta boxes.

## Method 2 — Upload via WordPress dashboard

1. Download the plugin ZIP file from [WordPress.org](https://wordpress.org/plugins/add-category-to-pages/)
2. Go to **Plugins → Add New**
3. Click **Upload Plugin**
4. Select the ZIP file and click **Install Now**
5. Click **Activate Plugin**

## Method 3 — Manual FTP installation

1. Download and extract the plugin ZIP file
2. Upload the `page-categorizer` folder to `/wp-content/plugins/`
3. Go to **Plugins → Installed Plugins**
4. Find **Page Categorizer** and click **Activate**

## After activation

No configuration is required. After activating the plugin:

- Go to **Pages → All Pages** and open any page to edit it
- You will see a **Categories** meta box and a **Tags** meta box in the sidebar (Gutenberg) or below the editor (Classic Editor)
- Assign categories and tags exactly as you would for a post

## Uninstalling

1. Go to **Plugins → Installed Plugins**
2. Click **Deactivate** under Page Categorizer
3. Click **Delete**

After deactivation, categories and tags previously assigned to pages remain in the database but will no longer be displayed or applied to pages. Reactivating the plugin restores full functionality without any data loss.
