# Page Categorizer

**Version:** 1.5.1
**Requires WordPress:** 6.0 or higher
**Requires PHP:** 7.4 or higher
**License:** GPL-2.0+
**Download:** [WordPress.org](https://wordpress.org/plugins/add-category-to-pages/)

Page Categorizer is a free WordPress plugin that extends the built-in category and tag taxonomies to WordPress Pages. By default, WordPress only allows categories and tags on Posts — this plugin adds that same capability to Pages with zero configuration.

## How it works

Once activated, the plugin registers the existing `category` and `post_tag` taxonomies for the `page` post type. From that point on:

- A **Categories** meta box appears on every Page editing screen
- A **Tags** meta box appears on every Page editing screen
- Pages assigned to a category appear on that category's archive page alongside posts
- Pages assigned to a tag appear on that tag's archive page alongside posts

No settings page. No configuration required. Activate and it works.

## Key features

**Assign categories to pages** — Associate one or more categories with any WordPress Page from the standard Page editing screen.

**Add tags to pages** — Add relevant tags to Pages just as you would for Posts, improving searchability and content discovery.

**Archive integration** — Pages automatically appear in category archive pages (`/category/your-category/`) and tag archive pages (`/tag/your-tag/`) alongside posts.

**Zero configuration** — No settings to configure. Activate the plugin and the functionality is immediately available on all Pages.

**Lightweight** — The entire plugin is two functions. No database tables, no options, no scripts or styles loaded.
